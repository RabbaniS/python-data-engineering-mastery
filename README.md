## How to use the daily folders

1. Read the topics and quick theory before coding.
2. Try the practice task without looking up a complete solution.
3. Answer the quick-check questions from memory, then verify your answers.
4. Commit your work and note one thing to revisit.

The PySpark days require Java and PySpark in addition to Python. Check the setup instructions for the PySpark version you choose before starting Day 15. Keep credentials and private data out of the repository.
