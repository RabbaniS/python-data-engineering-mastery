# Day 03: Conditions and Loops

## Topics
- `if`, `elif`, and `else`
- `for` loops and `range`
- `while`, `break`, and `continue`
- Looping through records and using `enumerate`

## Quick theory
- Conditions choose a code path; order branches from specific cases to general cases.
- `for` iterates over items in an iterable, while `while` repeats as long as a condition is true.
- `enumerate(items, start=1)` provides an index and item without managing a counter manually.
- Avoid changing a collection while iterating over it; build a new collection instead.
