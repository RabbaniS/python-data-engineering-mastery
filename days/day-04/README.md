# Day 04: Python Collections

## Topics
- Lists and tuples
- Dictionaries and sets
- Indexing, membership, and iteration
- Choosing a collection for a task

## Quick theory
- A list is ordered and mutable; a tuple is ordered and immutable.
- A dictionary maps unique, hashable keys to values and is useful for named record fields or lookups.
- A set stores unique values and supports fast membership tests and set operations.
- Choose collections based on required behavior, not just syntax familiarity.
